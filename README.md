## How I Work

1. **Start from the decision.** What business question does this data need to answer?
2. **Automate the boring parts.** Repeatable pipelines (`SQL`, `Python`, `Power Query`) instead of one-off spreadsheets.
3. **Deliver the "so what".** Dashboards and summaries that point to an action, not just a chart.
